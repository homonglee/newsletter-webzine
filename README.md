# Letterly — 뉴스레터 웹진

이미지와 글을 넣어 아름다운 뉴스레터를 만들고 링크로 공유하는 브라우저 기반 웹앱입니다.

## 기능
- 이미지 자동 리사이즈·WEBP 압축
- 뉴스레터 작성, 수정, 삭제(확인 절차), 중요 글 상단 고정
- 블로그형 과거 뉴스레터 아카이브 및 검색
- 서버/회원가입 없이 내용이 포함된 독립 공유 링크 생성
- 브라우저 로컬 저장 및 JSON 백업/복원

## 개발
```bash
npm test
npm run dev
```

> 작성 데이터는 현재 브라우저에 저장됩니다. 공유 링크를 받은 사람은 해당 뉴스레터를 읽을 수 있지만 발행자의 편집 권한이나 다른 글은 볼 수 없습니다.
