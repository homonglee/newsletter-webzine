# Letterly — 뉴스레터 웹진

이미지와 글을 넣어 아름다운 뉴스레터를 만들고 링크로 공유하는 브라우저 기반 웹앱입니다.

## 기능
- 글 직접 입력 또는 TXT·MD 원고 첨부
- 제목·첫 줄 소개·본문을 각각 분리 입력하고, 기본 제목 `호몽의 News Letter`를 자유롭게 수정
- 원고의 핵심 문단을 분석해 한 줄 소개와 Markdown 본문 초안 자동 구성
- 일반 TXT의 짧은 제목형 문장, 열거 항목을 소제목·목록으로 자동 변환
- Markdown 소제목·목록·인용문·강조를 안전한 웹진 타이포그래피로 렌더링
- 최대 8장의 이미지 동시 업로드, 자동 리사이즈·WEBP 압축
- 이미지 순서 변경·삭제 및 에디토리얼/갤러리/클래식 자동 배치
- 독자 화면에서 이미지 원본 비율을 보존하고 화면 폭에 따라 여백·간격을 유동 조절
- 생성 결과를 발행 전에 다시 편집
- 뉴스레터 작성, 수정, 삭제(확인 절차), 중요 글 상단 고정
- 블로그형 과거 뉴스레터 아카이브 및 검색
- 발행 데이터를 서버 저장소에 보관하고 `https://homong-app.com/newsletter/s/8자리코드` 형식의 간결한 공유 링크 생성
- 공유 주소에서는 작성기·검색·아카이브 없이 해당 뉴스레터 한 편만 독자 전용 화면으로 표시
- 카카오톡·Telegram 등 링크 미리보기에 뉴스레터 제목, 첫 줄 소개, 첫 번째 대표 이미지 제공
- 기존 `?letter=` 형식의 공유 링크도 계속 열 수 있도록 하위 호환
- 작성 아카이브는 브라우저 로컬에 저장

## 개발
```bash
npm test
npm run dev
```

> 작성 아카이브는 현재 브라우저에 저장됩니다. 발행된 공유본은 연결된 Upstash Redis 무료 저장소에 최대 1년간 보관되며, 링크를 받은 사람은 해당 뉴스레터만 읽을 수 있습니다. 발행자의 편집 권한이나 다른 글은 공개되지 않습니다.
